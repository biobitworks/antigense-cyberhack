**Project description**
Antigense is an evidence-driven agentic cyberdefense prototype addressing a dangerous failure mode: a corrupted AI-worker result causes software to fail open and authorize an unsafe request. We reproduce this fault using controlled software-injected bytes, not physical hardware damage. A pinned Semgrep rule finds the fallback (1 finding before the fixture repair; 0 after), and a four-case regression matrix verifies denial of unauthorized work while preserving authorized requests. AI analysis is advisory; a human-review gate selects the bounded correction.

Our innovation is inspectable chain-of-custody: each incident step becomes a content-addressed Fractal Custody Object (FCO), linked by typed predecessors in a Fractal Custody Graph (FCG) and committed to a deterministic Merkle Mountain Range (MMR). Browser and CLI independent recomputation check the recorded evidence; a separate executed local run contains 12 MMR leaves including a persisted review action.

Historical sponsor execution: Semgrep local scans; Akash GPU deployment and Qwen inference (HTTP 200) with API-reported close success, with advice not applied; ClickHouse Cloud 11-checkpoint incident ingestion and exact readback. Pi Security API execution remains NOT_TESTED. The narrated demo is recorded playback, not live new cloud execution. We preserve failed calls, unknown billing, absent GPU attestation and unsigned actor identity instead of masking them.

**Lessons learned**
A source hash is necessary but not sufficient: the exact bytes must be retained, parent/custody relationships independently recomputed and historical failures preserved. Initial Semgrep scans missed other ways to execute fixture code, so broad code review and independent falsifiers matter. Model-generated advice has no authority to patch. A provider close API success does not prove final closed-state readback, and a current live browser proof is not proof the sponsor was re-executed in that session. We also learned to freeze scene and frame timing instead of assuming a narration/video trim leaves alignment unchanged.
