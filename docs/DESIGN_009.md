# Antigense 009 successor design

User intent: high-quality Akash, Semgrep and Pi usage with hardware, AI, human and error in one demonstrable loop; prepare repo, Vercel permalink, script, silent video then human voice. Existing 008R1 is frozen and retained.

Selected design: corrupt the exact arithmetic-output bytes in a disposable software simulation. The unsafe fallback turns an availability/integrity failure into a reproducible authorization bypass in a pure boolean fixture. Semgrep identifies the fixed source location. Local AI executes now; the same minimal facts may go to an authenticated Akash GPU endpoint after onboarding. Pi receives a reproducible review packet after onboarding. An unsigned local review action is bound to the current MMR root before the pinned safe implementation is selected. The unauthorized and healthy-authorized paths are verified. No generated patch is executed.

Alternatives considered: thermal stress would require measured sensors, risky sustained load and a less deterministic trigger; a historical Titan replay is a better next dataset adapter but license/access review is incomplete. The safe checksum corruption is the first execution lane, not evidence of a physical hardware fault.

Public MVP is sanitized recorded evidence. Local cockpit binds loopback, rejects foreign Host/Origin, requires a session token for mutations, serves only fixed public paths and polls OS counters. The 3D geometry is illustrative. No private host identity, code from other repositories, cloud credentials or raw restricted dataset rows are exported.

Freeze covers the declared graph source list; executable results are added as FCO/MMR objects. Each observation captures source/state, checks, classification and diagnostic. Determinism applies to declared serialization/hashing/classification and the injected bytes. Live timing and model text may differ; those observed bytes are committed rather than invented as repeatable model output. Anticube SELF_SAFE stays null until real proof and authorization are available.

Success: real Semgrep finding then clean custom-rule scan; observed inference text separately labeled; stale approval fails; four-case authorization matrix passes; all prefix hashes recompute independently in Python and browser; public page and desktop/mobile have no overflow; silent screen recording shows evidence rather than sponsor logo animation. Akash attestation, Pi execution, IEEE training and authenticated human signatures are NOT_TESTED.
